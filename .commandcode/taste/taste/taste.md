# Taste
- Comfortable delegating programming-language / tech-stack decisions to the agent ("use any language you think best"), rather than mandating a specific one. Confidence: 0.5
- Wants desktop tools delivered as native applications ("result in native application"), not web/Electron wrappers; language is free as long as the outcome is a real native app. Confidence: 0.6
- Wants direct-manipulation mouse/trackpad gestures in desktop UIs (scroll to zoom, scroll/drag to pan) rather than relying only on keyboard shortcuts or toolbar buttons. Confidence: 0.5
- Sensitive to perceived latency in interactive features and expects the agent to diagnose the root cause and tighten it, not just accept it. Confidence: 0.5
- When a claimed fix doesn't actually work, reports it terse and direct ("still not working") and expects the agent to keep investigating the true root cause with real evidence rather than offer another guess or declare victory. Confidence: 0.4
- Wants full keyboard-driven navigation in desktop UIs — arrow keys move a highlighted selection and Enter commits it — not just numeric/single-key hotkeys; features should scale gracefully (e.g. beyond a fixed set of hotkeys). Confidence: 0.5
- Expects the intended and current items to be visually distinguished with color (e.g. a hover/selection highlight distinct from the "active" indicator) so state is unambiguous. Confidence: 0.45
- Wants hardware/device settings exposed as user-selectable options (e.g. choosing the audio output device) rather than pinned to the system default, explicitly so the app scales as more devices are added later. Confidence: 0.4
- Asks the agent to confirm whether a capability actually works (e.g. "can it handle stereo MP3 well?") and expects it to be verified with concrete evidence/tests rather than assumed. Confidence: 0.4
- Expects desktop apps to be OS-integrated with a proper custom icon and app identity (the macOS Dock/Cmd+Tab entry showing the app's own name and icon), not just a bare binary that shows the system's generic icon. Confidence: 0.45
